🐾 Spring Petclinic AI:
Erweiterte Version der klassischen Spring Petclinic mit modernem Frontend und optionaler KI-Integration.

🔧 Tech Stack:
Backend: Java, Spring Boot, JPA
Frontend: Flutter (Web / Desktop / Mobile)
Datenbank: H2 (Dev), optional MySQL/PostgreSQL

🚀 Starten:
Backend
cd backend
./mvnw spring-boot:run

→ http://localhost:9966/petclinic

Frontend:
cd frontend
flutter pub get
flutter run

🌿 Branches:
master – Hauptversion
frontend_mobile – Mobile Layout
frontend_desktop - Desktop Layout

✨ Features:
Besitzer- & Tierverwaltung
Terminverwaltung
Responsive UI mit Sidebar
Login / Logout
KI-Funktionen
